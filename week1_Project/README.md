# Week 1 Project - Analyze Student Marks Dataset

## Internship
BeeSkilled – Data Science with Python Internship

## Objective

The objective of this project is to learn the basics of Data Science using Python, Pandas, and NumPy by analyzing a student marks dataset.

---

## Dataset

**Dataset Name:** StudentsPerformance.csv

The dataset contains information about students including:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch Type
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

---

## Project Tasks

- Load the dataset using Pandas.
- Check for missing values.
- Clean missing data (if available).
- Calculate average scores.
- Calculate maximum scores.
- Calculate minimum scores.
- Display the results using Pandas.

---
